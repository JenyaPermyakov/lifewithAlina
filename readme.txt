Life with Alina

Это pet-проект Telegram-бота для учета и простой аналитики сна.

Бот помогает пользователю:
- добавлять записи ночного и дневного сна;
- указывать дату, время засыпания и время пробуждения;
- видеть длительность сна;
- смотреть статистику за день, 7 дней и 30 дней;
- строить график сна за последние дни;
- просматривать последние записи;
- удалять последнюю ошибочную запись;
- получать ежедневные напоминания.

В проекте используются:
- Python;
- aiogram для Telegram-бота;
- PostgreSQL для хранения данных;
- SQLAlchemy и asyncpg для работы с базой;
- matplotlib для построения графиков;
- Railway для деплоя.

Основные файлы проекта:
- bot.py - запуск бота и подключение роутеров;
- handlers/ - обработчики сообщений пользователя;
- services/ - бизнес-логика аналитики и напоминаний;
- database/ - подключение к базе и модели таблиц;
- utils/ - вспомогательные функции для времени и графиков.

Для запуска нужны переменные окружения:
- BOT_TOKEN - токен Telegram-бота из BotFather;
- DATABASE_URL - строка подключения к PostgreSQL.

Проект создан для практики разработки Telegram-ботов, работы с базой данных,
аналитики пользовательских данных и деплоя Python-приложения на сервер.
